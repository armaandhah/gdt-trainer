# GD&T Trainer

An interactive study tool for Geometric Dimensioning & Tolerancing (ASME Y14.5-2018).

- **Symbols**: all 14 characteristics with datum rules, modifier rules, tolerance zones, and real examples
- **Quiz**: 10-question rounds covering symbol ID, MMC/LMC, bonus tolerance, datums, and Rule #1
- **Bonus calc**: position tolerance accept/reject with bonus tolerance, virtual condition, and a zone plot
- **Frame reader**: build a feature control frame and get a plain-English reading plus validity checks

Single static `index.html`, no build step. Hosted with GitHub Pages.
