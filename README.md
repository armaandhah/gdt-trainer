# GD&T Trainer

Learn engineering drawings and GD&T (ASME Y14.5-2018) from zero.

- **Start here**: 12 illustrated lessons from "what is a drawing" through views, line types, dimensions, tolerances, datums, and feature control frames, with worked examples and a glossary
- **Read a drawing**: two full example drawings (shock mount plate, pivot shaft) with clickable callouts explaining what each one means, how it's inspected, and accept/reject examples
- **Symbols**: all 14 characteristics, each with an illustrated callout + tolerance zone and real measurement cases
- **Quiz**: drawing basics, symbol ID, GD&T concepts, and questions on the example drawings
- **Bonus calc**: position tolerance accept/reject with bonus tolerance and a zone plot
- **Frame reader**: build a feature control frame and get a plain-English reading plus validity checks

## Editing
Source lives in `src/` (CSS, HTML body, JS modules). Run `python3 build.py` to regenerate the single-file `index.html` that GitHub Pages serves.
